# Cat-Carried-Butterfly-RUS

Неофициальный русификатор для игры **衔蝶 / Cat Carried Butterfly**.

---

## О проекте

Всем привет!

Меня зовут **Серго (Tidus)**. Я полностью перевёл и адаптировал на русский язык игру **衔蝶 / Cat Carried Butterfly**.

Для меня это был один из самых сложных переводов. Игра оказалась непростой не только по объёму текста, но и по структуре повествования: дневники, записки, скрытые надписи, китайский фольклор, эмоциональные сцены и сюжетные детали, которые важно было передать понятно для русскоязычного игрока.

Я старался сделать не просто дословный перевод, а полноценную русскую версию, сохранив атмосферу оригинала, настроение сцен и общий стиль игры.

Надеюсь, вам понравится мой перевод этой замечательной игры.

Приятной игры!

## Скачать

Скачать актуальную версию русификатора можно в разделе:

**Releases**

На странице релиза находится установщик русификатора.

---

## Установка

1. Скачайте установщик из раздела **Releases**.
2. Запустите установщик.
3. Укажите папку, в которую установлена игра **Cat Carried Butterfly / 衔蝶**.
4. Дождитесь завершения установки.
5. Запустите игру.

Установщик заменяет файл `xiandie.pck` на русифицированную версию и создаёт резервную копию оригинального файла.

---

## Удаление русификатора

При удалении русификатора через стандартное удаление программ Windows оригинальный файл игры будет восстановлен из резервной копии, если она была создана установщиком.

---

## Проверка файла

Для прозрачности к релизу добавлен **SHA-256 хеш** установщика.
572a7b509d987c057a1daf133444988df9996a268365034fec5f6258156d3007

Вы можете самостоятельно проверить скачанный файл и убедиться, что он не был изменён.

Также при необходимости можно проверить установщик через **VirusTotal**.
